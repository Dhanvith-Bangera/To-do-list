# To-Do List Web App

A simple and interactive To-Do List web application built using HTML, CSS, and Vanilla JavaScript.

## Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Press Enter to add a task
- Instant UI updates without page reload

## Technologies Used

- HTML
- CSS
- Vanilla JavaScript
- VS Code
- Live Server

## How to Run

1. Download or clone this repository.
2. Open the project in VS Code.
3. Open `index.html` using Live Server.
4. The To-Do List will open in the browser.

## Project Structure

- `index.html` - Structure of the application
- `style.css` - Styling of the application
- `script.js` - Functionality of the To-Do List
